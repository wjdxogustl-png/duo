## 3. 완료된 기능

### 3-1. 사용자 기능
1. **다국어 대화 온보딩** — 5개 언어로 대화하며 정보를 저장하고 빠진 것만 되묻기
2. **정착 안정도 진단** — 점수가 기준 미달이면 멘토·상담 연결을 먼저 제안
3. **맞춤 정착 로드맵** — 체류 기간·자녀·직업에 맞춘 단계별 할 일, 단계 완료 처리
4. **경남 지원사업 연결** — 시·군 지원사업을 출처와 함께 검색, DB에 없으면 공식 상담 창구 안내
5. **신청서 초안** — 모든 지원사업 대상, 화면에서 수정 → Word 내려받기·복사, 고유식별정보 자동 삭제
6. **능동 케어** — 재방문 시 체류 종료 D-day와 남은 단계를 먼저 브리핑 (6시간 제한)
7. **액션 카드** — 신청서 만들기, 상담 창구 연락, 지원사업 출처 열기 버튼 제안 (번호·주소는 DB·공식 창구만 허용). 창구 카드를 누르면 준비물·할 말·다음 단계 안내
8. **위기 상황 우선 연결** — 폭력·임금체불·생명 위험이면 112·119·1366·1350 등 공식 창구를 지원사업보다 먼저 제안
9. **개인정보 배려** — 고유식별정보 자동 삭제, 저장 위치·삭제 방법 안내
10. **에이전트 작업 기록** — 어떤 도구를 왜 호출했는지 화면에 그대로 공개

### 3-2. 에이전트 도구 (9개)
| 도구 | 역할 |
|---|---|
| `save_profile` | 온보딩 정보 저장, 빠진 항목 되묻기 |
| `score_risk` | 정착 안정도 채점 |
| `build_roadmap` | 규칙 기반 정착 로드맵 생성 |
| `update_roadmap_step` | 로드맵 단계 완료 처리 |
| `search_programs` | 지원사업 DB 검색 (출처 포함) |
| `set_dday_reminder` | 체류 종료일 D-day |
| `draft_application` | 신청서 초안 작성 |
| `note_situation` | 맥락으로 판단한 숨은 필요 기억 |
| `suggest_actions` | 다음 행동 카드 제안 |

### 3-3. API
`/api/chat`, `/api/briefing/{id}`, `/api/state/{id}`, `/api/programs`, `/api/hotlines`, `/api/files/{name}`, `/api/i18n`, `/api/health`

### 3-4. 화면
- 채팅 + 오른쪽 패널 4개: 경남 지도, 에이전트가 이해한 상황, 나의 정착 로드맵(D-day), 에이전트 작업 기록
- 액션 카드 버튼, 신청서 초안 편집 화면
- 라이트/다크 모드, 5개 언어 전환
